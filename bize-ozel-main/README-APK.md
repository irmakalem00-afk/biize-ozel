# Bize Özel — Android APK Paketi

Mevcut HTML, CSS ve JavaScript tasarımı korunarak Capacitor tabanlı Android hazırlığı eklenmiştir.

## Komutlar

```bash
npm install
npm run android:prepare
npm run android:open
```

Kurulabilir debug APK üretmek için:

```bash
npm run android:apk
```

Çıktı: `APK-CIKTISI/Bize-Ozel.apk`

GitHub Actions ile otomatik derleme de `.github/workflows/android-apk.yml` dosyasında hazırdır.
